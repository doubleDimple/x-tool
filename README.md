# X-Tool

Chrome 插件：扫描你在 X / Twitter 上的关注和粉丝，找出：

- **未回关**：你关注了对方，对方没有关注你
- **互关**：双向关注
- **单向粉**：对方关注了你，你没有回关

全部在浏览器本地完成，不上传账号数据。

## 安装（开发版）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选中本仓库根目录（里面有 `manifest.json` 的那一层）
5. 登录 [x.com](https://x.com)，点工具栏里的 X-Tool 图标，会弹出窗口

扫描或取关时请不要点到弹窗外面，否则会中断。关注/粉丝很多时会分页拉取，并自动放慢速度，避免触发限制。

## 它怎么工作

插件使用你已经登录的 X 网页会话：

1. 优先走 X 网页自己的 GraphQL 接口（Following / Followers）
2. 接口失效时，自动改用 `friends/list`、`followers/list` 备用接口
3. 在本地做集合差：未回关 = 关注 − 粉丝

X 会不定期更换 GraphQL queryId。插件会：

- 从当前打开的 x.com 页面捕获真实请求
- 尝试从网页脚本里发现最新 queryId
- 再退回硬编码默认值和 REST 备用接口

## 注意

- 必须先在同一个 Chrome 里登录 X
- 这是读自己的关注关系，不做批量取关
- 拉列表过快可能触发验证码或短暂限制，所以默认有间隔
- 使用内部接口可能不符合 X 服务条款，请自行判断风险
- 本工具与 X Corp. 无关
